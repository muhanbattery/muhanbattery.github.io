Muhanbattery Uploader

A private desktop tool used only by the owner of the YouTube channel "무한배터리" (youtube.com/@muhanbattery) to upload and manage videos on that channel with the YouTube Data API. It is not offered to the public and has no other users.

Privacy Policy

Last updated: November 13, 2026

1. What data the app accesses

The app uses the YouTube Data API v3 with the channel owner's own Google account (OAuth 2.0). It accesses only the owner's own channel to upload videos; set titles, descriptions, tags, thumbnails and privacy/schedule settings; add the owner's videos to the owner's playlists; and read the list of the owner's own uploads to find the matching video.

2. How the data is stored

The OAuth access/refresh token is stored only on the owner's personal computer (a local file). Video files and metadata come from the owner's own computer. No data is sent to any server other than Google/YouTube. The app has no database, no website backend, no analytics and no advertising.

3. Sharing

No data is sold, shared or disclosed to any third party.

4. Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube API Services are used in accordance with the YouTube Terms of Service and the Google Privacy Policy.

5. Revoking access and deletion

The owner can revoke the app's access at any time at myaccount.google.com/permissions, and deleting the local token file removes all stored credentials.

6. Contact

Questions about this policy: contact the channel owner through the email listed on the YouTube channel's About page.
